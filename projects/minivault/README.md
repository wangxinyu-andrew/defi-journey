# MiniVault

MiniVault is a minimal overcollateralized stablecoin protocol for learning DeFi.

This project is inspired by protocols like MakerDAO and Aave, but it is intentionally simplified.

## Core Question

Why does DeFi lending need liquidation?

## User Actions

1. Deposit ETH as collateral
2. Borrow mUSD against collateral
3. Repay mUSD
4. Withdraw collateral
5. Get liquidated if the collateral ratio becomes too low

## Status

This is a learning project, not production code.
